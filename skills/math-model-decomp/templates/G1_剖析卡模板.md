## 6. EDA 八步结论

> 说明：八步逐一给结论，禁止“已清洗”这类无证据表述；异常值判定走**双通道三分支**（与 SKILL §3 第 3 步口径一致，禁止一刀切剔除）：
> **通道 A（噪声型）**：无现实事件对应 **且** 剔除后关键下游指标变化 **≤5%** → 可剔除（走 1.5×IQR / 3σ 剔除或滤波）；
> **通道 B（因果事件型）**：异常点与现实事件时间窗重叠 **≥1 天** → **严禁剔除**，保留原值 + 因果机理解释（如疫情封控、极端暴雨）；
> **通道 C（无事件但改变趋势型）**：无事件对应且剔除后关键指标变化 **>5%** → **默认保留原值**，同时输出“剔除版/保留版”**双版本敏感性对照**，交 G2/G3 判定。
> “关键下游指标”由 G1 指定并在本卡第 6 字段登记。

| 步骤 | 检查项 | 结论（含数值） |
|---|---|---|
| 1 | 维度类型与真实语义 | `[行×列；连续/离散/标称/时序；离散 ID 识别为非数值]` |
| 2 | 缺失机制与填补依据 | `[缺失率 X%；机制 = 随机/非随机；填补法 = 拉格朗日插值/中位数]` |
| 3 | 极端异常值识别（双通道三分支 A/B/C） | `[1.5×IQR 与 3σ 命中 X 条；通道 A 噪声型剔除 Y 条（无事件且关键指标变化 ≤5%）、通道 B 因果事件型保留 Z 条及事件名（事件窗重叠 ≥1 天）、通道 C 保留 W 条（变化 >5%）+ 剔除版/保留版双版本敏感性对照]` |
| 4 | 分布偏度与峰度 | `[Skewness = X；Kurtosis = Y；是否 Box-Cox 变换]` |
| 5 | 多重共线性与降维 | `[最大 VIF = X（>10 则注明降维/正则化方案）]` |
| 6 | 累计销量核心样本筛选 | `[核心单品 X 个，占累计销量 **70%+**（近似二八法则工程口径）]` |
| 7 | 数据流向全局 DAG | `[节点与边的文字描述，或引用图件 figs/fig_XX_*.png]` |
| 8 | 本剖析卡交付 | `[8 字段是否齐全：是/否]` |
