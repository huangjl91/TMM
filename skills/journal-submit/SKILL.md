# 学术论文投稿全流程技能 (journal-submit)

## When to use

- 向 SCI/EI/SSCI 期刊或国内核心期刊正式投稿，需要筛选目标期刊并评估命中率与审稿周期。
- 收到审稿意见（Major/Minor Revision）后，需要逐条拆解意见、撰写回复矩阵并组织返修稿。
- 需要撰写 cover letter / 投稿信，论证研究新意与期刊 scope 的契合度。
- 投稿前需要做格式合规自查：作者贡献、利益冲突、伦理批件、数据可用性、查重与 AI 使用声明。
- 需要对照期刊 Guide for Authors 核查结构、摘要字数、图表分辨率与引用格式。
- 收到校样（proof）后需要逐字核对作者顺序、图表编号、参考文献与公式上下标。

### Do NOT use when

- 任务是学位论文（本科/硕士/博士毕业论文）的开题、写作或查重修改。
- 任务是数学建模竞赛限时论文写作，或 `math-model-*` 家族负责的 G0–G7 竞赛阶段产物。
- 任务是无需同行评审的内部报告、技术文档、会议海报或纯文献综述。
- 目标是改写/润色语言而无任何投稿流程产物需求（交由通用润色能力处理）。

## 输入 / 输出契约

路径基准：下表全部相对路径一律相对**项目工作区根**（非 skill 目录），首次使用前由总控创建缺失目录。

| 阶段 | 输入 | 输出产物 | 命名约定 |
|---|---|---|---|
| 阶段 1 选刊评估 | 稿件标题与摘要、学科分类、期刊候选列表 | `targeting/journal_scorecard.md` | 选刊评分卡，含四维打分表 |
| 阶段 2 稿件结构打磨 | 稿件全文、目标期刊 Aims & Scope | `manuscript/main.tex`（正文与图） | `manuscript/main.tex`、`manuscript/fig_XX_<slug>.png` |
| 阶段 3 格式与伦理合规 | 伦理批件、COI 表、作者贡献表、查重报告 | `manuscript/main.tex` 内声明文件 | 声明段并入正文末尾或独立文件 |
| 阶段 4 投稿与投稿信 | 评分卡、稿件定稿、推荐审稿人信息 | `submission/cover_letter.md` | 投稿信，含新意 3 点与 scope 论证 |
| 阶段 5 审稿意见回复 | 审稿意见原文、返修稿 | `review/response_matrix.md` | 逐条回复矩阵，R1.1 式编号 |

## 阶段流程（含 Checkpoint）

### 阶段 1 选刊评估

- 活动：范围（scope）匹配、影响因子与分区、审稿周期与录用率、版面费与开放获取选项、投稿系统要求。
- **Checkpoint 1**：《选刊评分卡》≥3 本候选期刊，含 scope 匹配度/审稿周期/命中率/费用四维打分，最终选 1 主 1 备。

### 阶段 2 稿件结构打磨

- 活动：IMRaD 结构完整性、图表自明性、摘要字数与结构、关键词 MeSH 主题词与自由词搭配。
- **Checkpoint 2**：每张图脱离正文可独立读懂；摘要 ≤ 目标期刊限额；关键词 4~5 个含至少 1 个主题词。

### 阶段 3 格式与伦理合规

- 活动：作者贡献（CRediT 分类）、利益冲突声明、伦理批件号、数据可用性声明、查重与 AI 使用声明、图片分辨率与引用格式。
- **Checkpoint 3**：查重率符合期刊阈值；伦理与 COI 声明齐全；图表分辨率 ≥300 DPI、引用格式符合期刊 Guide。

### 阶段 4 投稿与投稿信

- 活动：cover letter 撰写、推荐/回避审稿人、声明文件与补充材料上传、投稿系统字段填写。
- **Checkpoint 4**：cover letter 含研究新意 3 点、与 scope 的契合论证、无一稿多投声明。

### 阶段 5 审稿意见回复

- 活动：逐条编号回复、改稿留痕（修订模式或标注版）、反驳点文献支撑、回复顺序与意见原文对齐。
- **Checkpoint 5**：《回复矩阵》8 列齐全，每条意见均有 Response + 修改位置定位（`文件:行` 或节号，返修稿另注页·行）+ 状态四值（待回复 / 接受 / 部分接受 / 未采纳（反驳））；未采纳项均有支撑文献与补偿动作。

### 阶段 6 返修与校样

- 活动：返修信（Response Letter）汇总、逐字校样核对、清样阶段仅允许勘误不允许改内容。
- **Checkpoint 6**：校样核对表逐项签核（作者顺序/图表编号/参考文献/公式上下标）；返修在截止日前 3 天提交。

## 质量门禁清单

路径基准：本清单中出现的全部产物路径均相对**项目工作区根**（与上方 I/O 契约表一致，非 skill 目录）。

- [ ] 《选刊评分卡》≥3 本候选，四维打分齐全，已定 1 主 1 备（产物 `targeting/journal_scorecard.md`）（阶段 1）
- [ ] cover letter 中对目标期刊 scope 的契合论证逐条落字（产物 `submission/cover_letter.md`）（阶段 4）
- [ ] 稿件 IMRaD 结构完整，方法与结果可复现信息齐备（产物 `manuscript/main.tex`）（阶段 2）
- [ ] 全部图表自明（脱离正文可读），分辨率 ≥300 DPI（产物 `manuscript/fig_XX_<slug>.png`）（阶段 2、3）
- [ ] 摘要长度 ≤ 目标期刊限额，结构含目的/方法/结果/结论（位置 `manuscript/main.tex` Abstract 节）（阶段 2）
- [ ] 关键词 4~5 个且含至少 1 个 MeSH 主题词（位置 `manuscript/main.tex` Abstract 节）（阶段 2）
- [ ] 伦理批件号与 COI 声明齐全，数据可用性声明已写（产物 `manuscript/main.tex` 内声明文件）（阶段 3）
- [ ] 查重率达标，符合期刊公布阈值（凭证：投稿系统查重报告，归档 submission/plagiarism_report.pdf）（阶段 3、4）
- [ ] CRediT 作者贡献与 ICMJE 作者资格判定完成（产物 `manuscript/main.tex` 内作者贡献表）（阶段 3）
- [ ] cover letter 含研究新意 3 点与无一稿多投声明（产物 `submission/cover_letter.md`）（阶段 4）
- [ ] 《回复矩阵》零遗漏：每条意见均有回复类型、回复正文与修改位置（`文件:行` 或节号）（产物 `review/response_matrix.md`）（阶段 5）
- [ ] 全部未采纳（反驳）意见均有支撑文献 `1~5 个（建议 3~5 个）`，非凭主观断言（位置 `review/response_matrix.md` 支撑文献列）（阶段 5）
- [ ] 核对表零遗漏：作者顺序/图表编号/参考文献/公式上下标逐项签核（产物 `proof/proof_checklist.md`）（阶段 6）
- [ ] AI 使用声明已按期刊政策如实写入（位置 `manuscript/main.tex` 声明段）（阶段 3）
- [ ] 版面费与开放获取费用已确认并获经费方同意（凭证：经费方书面确认，随 `submission/` 材料归档）（阶段 1）

## 本阶段须通过的门禁

本阶段须通过的门禁 = 上方「质量门禁清单」中带（阶段 N）标注且包含当前阶段编号的全部勾选项（跨阶段条目如（阶段 3、4）分别计入阶段 3 与阶段 4）：任一项未勾选即判该阶段 Checkpoint 不通过，对应产物退回本阶段修订，复检全绿后方可放行下一阶段。

## templates/ 使用说明

- 配套模板：`journal-submit/templates/审稿意见回复模板.md`（相对 skill 目录）。
- 使用方式：复制模板为 `review/response_matrix.md`（相对项目工作区根），按意见原文逐条填充固定 8 列：意见编号 / 审稿人原文 / 回复类型（修改|解释|部分采纳）/ 修改动作 / 回复正文（`First, we thank…` 句式）/ 修改位置（`文件:行` 或节号，返修稿另注页·行）/ 状态（待回复 / 接受 / 部分接受 / 未采纳（反驳））/ 支撑文献。
- 转录审稿意见时保留期刊原始编号层级（如 1、1.1、2），不得合并或改序。
- 标为未采纳（反驳）的意见必须同时给出客观理由、支撑文献 `1~5 个（建议 3~5 个）` 与至少 1 项补偿动作，缺一即判回复矩阵不完整。

## references/

- ICMJE 推荐（作者资格与披露）：作者资格四准则与病例报告等具体场景的判定依据。
- CRediT 作者贡献分类法：14 类标准化贡献角色，用于作者贡献声明。
- COPE 伦理指南：撤稿、同行评审伦理、作者争议处理流程。
- 各期刊 Guide for Authors：投稿前必须下载当期版本，核对结构、字数、图表与引用格式要求。

## 常见错误

- 未按目标期刊 Guide 调整格式，投稿系统初审即被 desk reject。
- 回复矩阵漏条：只回主要意见、跳过小意见或附录意见，返修被再次退回。
- 图表非自明：图题、图例、坐标轴信息不全，审稿人无法脱离正文理解。
- 伦理或利益冲突声明缺失，录用阶段被要求补交甚至撤稿。
- 返修超过截止日期未申请延期，被系统判定为弃稿。
- 一稿多投或多期刊并投，触碰学术不端红线。
- 摘要超长或关键词不合规范，被编辑部打回重投。
- 反驳审稿人时无文献支撑，仅表达主观不同意，导致二次修回恶化。
- 校样阶段未核对作者顺序与参考文献，错误在见刊后无法更正。
