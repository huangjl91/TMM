## 【铁律】核心禁令

- **【铁律】** 本技能（论文排版引擎）所有产物必须可追溯、可复算、可复现；任何无法回溯到源头的数字一律视为无效。
- **【铁律】** 阶段收口处必须通过 `scripts/validate_skills.py` 机检，未通过不得进入下游阶段。
- **【严禁】** 交付物中出现调试残留与 AI 解释口吻。
- **【严禁】** 裸写相对路径；`<project>` 与 `<skill>` 两套基准严禁混用。

本技能负责数学建模竞赛的 **法定硬性骨架执行、LaTeX 论文排版、版面零混乱规整、纯黑字色合规、篇幅精准控制、四重交付自审**。

## 1. 论文法定八大硬性结构骨架 (Mandatory Paper Structure Backbone)

竞赛论文必须严格遵循以下**八大核心硬性骨架**，且**这八大核心结构的标题必须一律强制以居中标题形式排版 (`\centering`)**，章节层级严谨；其余内容（如数据预处理/EDA、政策备忘录 Policy Memo、附录支撑材料等）根据赛题类型自由发挥融入：

```
+--------------------------------------------------------------------------------------+
|                        论文法定核心骨架 (Mandatory Backbone)                         |
+--------------------------------------------------------------------------------------+
| 1. 摘要与关键词 (Abstract & Keywords)                                                |
|    - 【绝对严禁出现任何公式和括号】！中段“针对问题X”加粗，末段特色；                 |
|      纯黑字；关键词 4~5 个。                                                         |
| 2. 问题重述 (Problem Restatement)                                                    |
|    - 简练叙述，严禁照抄原题大段背景；概括背景与各问核心任务，                        |
|      严格控制在 1 页以内。                                                           |
| 3. 问题分析 (Problem Analysis)                                                       |
|    - 客观剖析系统因果机制与变量流向；                                                |
|      【绝对严禁在论文中写“出题人意图/考什么”！】                                     |
| 4. 模型假设与符号说明 (Model Assumptions & Notation)                                 |
|    - 模型假设：每条尽量不超过一行，简短有力，                                        |
|      严格统一采用 (1)(2)(3) 格式；                                                   |
|    - 符号说明：                                                                      |
|      统一使用规范紧凑的学术三线表（符号 / 定义域与物理含义 / SI 单位）。             |
| 5. 每一个问题的模型建立与求解 (Model Formulation & Solution for Each Question)       |
|    - 按照“5.1 问题一的模型建立与求解”、                                              |
|      “5.2 问题二的模型建立与求解”等清晰分节展开；                                    |
|    - 扎实机理推导（公式夹心饼三步走），融入契合本题的机理微创新，                    |
|      数值绝对冻结；                                                                  |
|    - 严禁分析算法大 O 复杂度与硬件跑分表；                                           |
|      图表下方仅简明交代“这是什么图”。                                                |
| 6. 灵敏度分析 (Sensitivity Analysis)                                                 |
|    - 针对核心输入参数施加 ±5%、±10%、±20% 扰动测试，                                 |
|      绘制灵敏度响应图，论证模型鲁棒性。                                              |
| 7. 模型的评价（Model Evaluation: 仅限优缺点）                                        |
|    - 只写“模型的优缺点”（优点与缺点），其余一律不写，                                |
|      统一采用 (1)(2)(3) 简短呈现。                                                   |
| 8. 参考文献 (References)                                                             |
|    - 1~5 个（建议 3~5 个），仅写论文中核心引用的知识文献，网上精确可查；             |
|      写完主体彻底结束！                                                              |
| ------------------------------------------------------------------------------------ |
| ★ 标题居中铁律：上述 1~8 八大法定结构的大标题必须全部以居中大标题(\centering)排版！  |
| [其余自由发挥项]：数据探索清洗(EDA)、政策备忘录(Memo)、附录纯净防御代码与支撑材料等。|
+--------------------------------------------------------------------------------------+
```

## 2. 摘要标准生成规则与防线 (Abstract Generation Rules)

> **【最高优先硬性禁令：摘要绝对不准出现公式和括号】**
> 1. **严禁出现任何公式**：摘要中绝对不允许出现任何独立公式块、行内数学公式或 LaTeX 数学符号（严禁出现 `$x_i$`、`$f(x)$`、`$\lambda$` 等）；所有数量关系、变量与算法机理必须全部转化为流畅、纯粹的自然语言学术陈述！
> 2. **严禁出现任何括号**：摘要中绝对不允许出现任何形式的中文或英文括号（严禁使用 `()`、`（）`、`[]`、`【】` 等任何括号！）；所有需要解释说明的补充信息、缩写或数据，必须直接通过逗号或句号融入主谓宾完整的自然句子中，绝不能偷懒使用括号补充！

摘要是论文的“黄金第一页”，必须严格按照以下段落逻辑层层推进，并严守格式红线：

### 2.1 段落结构逐段推进规范
- **第一段：背景与核心问题**
  - 第一句进行背景描述，阐述研究相关的大背景情况；
  - 第二句提出研究问题，明确本次研究聚焦的核心问题。
- **第二至五/六段：数据处理与各问分步求解（段首引导词必须加粗）**
  - **第二段（数据处理 / 系统机理抽象）**：
    - 若赛题包含数据附件：说明对数据进行的数据收集、缺失清洗、异常值过滤与时空因果隔离等操作；
    - 若赛题为纯机理/动力学/无数据题（如国赛A题）：本段自适应调整为对物理系统核心机理、状态空间与拓扑关系的精简数学抽象，随后直接推进“针对问题一”，严禁强行编造虚假的数据清洗过程；
  - **第三段（问题一）**：段首强制加粗“\textbf{针对问题一}”，先说明问题一具体是什么，接着阐述针对该问题的求解过程与算法思路，最后说明求解得出的核心量化结果（关键结果加粗）；
  - **第四段（问题二）**：段首强制加粗“\textbf{针对问题二}”，按照同样方式，先明确问题二具体内容，再说明求解过程和最终结果；
  - **第五段（问题三）**：段首强制加粗“\textbf{针对问题三}”，先指出问题三具体内容，然后说明求解办法和得出的量化结果；
  - **第六段（问题四，若有）**：段首强制加粗“\textbf{针对问题四}”，先界定问题四具体内容，再说明求解过程和最终量化结果。
- **最后一段：综合成果与特色创新总结**
  - 对整个研究的成果、实际应用价值进行综合概括；
  - 明确提炼本研究的机理微创新、特色机制或稳健性等突出亮点。
- **摘要三维量化定义（硬性）**：**三维量化 = 数据维度（样本量/覆盖率/清洗比例）× 方法维度（模型/算法/参数规模）× 结果维度（核心指标值/提升幅度/误差界）**，三者至少各出现一个可核验数字；摘要若缺任一维，判 CB-8 不通过。

### 2.2 摘要编写要求与硬性禁令 (Abstract Rules)
1. **绝对不允许出现任何公式**：摘要中严禁出现任何独立公式、行内公式符号（如 `$x_i$`、`$f(x)$`、`$\lambda$`），所有数量关系与模型逻辑必须转化为流畅纯粹的文字表述；
2. **绝对不允许出现任何括号**：摘要中严禁出现任何形式的中文或英文括号（严禁使用 `()`、`（）`、`[]`、`【】` 等），需补充的说明文字或数据直接使用逗号融入顺畅的主谓宾自然句子；
3. **允许出现些许核心数字**：允许并鼓励出现少许关键量化数值（如目标优化值、提升百分比、误差界等），用于支撑结论的客观性与说服力；
4. **“针对问题X”引导词与关键量化结果强制加粗**：摘要中每一问段首的“\textbf{针对问题一}”、“\textbf{针对问题二}”等引导词必须加粗突出；各问核心数值结果（如较基准提升百分比、最优决策值）在摘要中亦同步加粗；
5. **字色绝对纯黑**：全段加粗文字一律保持纯黑，严禁使用任何彩色加粗或彩色框。

### 2.3 关键词标准生成规则 (Keywords Generation Rules)
- **数量控制**：关键词严格选取 **4~5 个**，精炼准确，杜绝过多或过少；**三类合计口径**（合计 4~5 个：第一类 1~2、第二类 1~2、第三类 1）——三类相加不足 4 个或多于 5 个即判不合格；
- **三向覆盖选取法**（必须从以下三个方向均衡覆盖选取）：
  1. **研究问题相关的词（1~2 个）**：选取能代表本次研究核心对象与核心业务/物理问题的专有名词（如：`蔬菜补货定价`、`波浪能转换装置`、`列车运行调度`、`光伏功率预测`）；
  2. **使用型相关的词（1~2 个）**：选取研究中使用到的关键方法、分析工具、数学模型等专业词汇（如：`多目标混合整数规划`、`时间序列分解`、`双层规划模型`、`非线性动力学方程`）；
  3. **求解算法相关的词（1 个）**：选取研究中采用的主要求解算法或核心求解器名称（如：`自适应遗传算法`、`内点法`、`粒子群优化算法`、`分支定界法`、`Gurobi 求解器`）；
- **排版规范**：
  - 紧接摘要正文下方另起一行，顶格排版；
  - 中文格式：`\textbf{关键词：}词1；词2；词3；词4；词5`（分号隔开，纯黑文字）；
  - 英文格式：`\textbf{Keywords:} word1; word2; word3; word4; word5`。

### 2.4 美赛 English Abstract 规范（MCM/ICM 专用）
- **触发条件**：仅当参赛美赛 MCM/ICM 需提交英文摘要页（Summary Sheet）时启用；**国赛（CUMCM/CMC）不适用**，国赛只写中文摘要，严禁画蛇添足补英文摘要；
- **结构与篇幅**：**单段 150~250 词**，一段内依次覆盖 Problem Background / Methods / Key Results / Conclusion 四个信息块，段末单独另起一行列 Keywords（**4~5 个**，与中文关键词一一对应，词序一致）；
- **硬性规则**：
  1. 与中文摘要的**所有数字 100% 一致**（页码、数值、百分比、误差界一字不差），严禁英中两版各写一套结果；
  2. 与中文摘要同样**零公式、零括号**（禁止 `$...$`、`()`、`[]`、`{}`），机理一律转自然语言陈述；
  3. Keywords 与中文关键词**一一对应**（同义词不算对应，词序保持一致）；
  4. 关键量化结果沿用中文摘要的加粗策略，字色纯黑；
  5. 排版位置：Summary Sheet 首页独立成页，紧随标题与队号信息之后。

## 3. 论文版面规整与纯黑字色铁律 (Zero-Chaos & Pure Black Text Rule)

### 3.1 纯黑字体与禁彩铁律 (Strict Monochromatic Text: Pure Black #000000)
- **文字全篇纯黑**：论文正文文字、各级章节标题、图表标题 (Caption)、图注、公式推导、表格内文字、附录代码文字一律使用**纯黑色 (Pure Black, #000000)**；
- **严禁彩色文字**：严禁在正文中使用 `\textcolor{red}{...}`、`\textcolor{blue}{...}`、`\color{...}` 等彩色标记文字；严禁使用带彩色背景/彩色边框的提示框 (Callout Boxes)；
- **彻底消除超链接彩色方框与蓝字**：LaTeX 导言区 `hyperref` 宏包必须强制配置 `\hypersetup{hidelinks}` 或 `colorlinks=false`，彻底封杀默认出现的绿色方框、红色方框或蓝色超链接文字，确保所有引用文字呈现自然的纯黑印刷质感；
- **附录代码纯黑白/灰度排版**：`listings` 或 `minted` 代码环境严禁彩虹色语法高亮，必须使用纯黑色文本配合适度粗体/斜体或纯灰度 (Grayscale) 注释，确保黑白打印与线上评阅完全一致。

### 3.2 版面极度规整，杜绝混乱 (Zero-Chaos Layout Architecture)
- **版心与页边距规整**：上下左右严格对称统一（2.5cm / 1 inch），段首强制严格缩进 2 字符（中文 `\parindent 2em`，英文相应缩进），行距严格统一定为 1.25~1.35 倍，严禁段落间距随意忽大忽小；
- **消除孤行孤字**：导言区强制设置 `\clubpenalty=10000` 与 `\widowpenalty=10000`，彻底杜绝孤行孤字出现在页首或页末；
- **浮动体严格就近排版，杜绝大面积空白与图文脱节**：
  - 所有图表紧随正文首次引用的位置下方出现，优先采用 `[htbp]` 或 `[H]` 参数；
  - 严禁图表飘到其他无关章节，严禁排版出现半页乃至大半页的悬空空白；
- **表格极度规范（学术标准三线表）**：
  - 一律使用专业三线表宏包 `booktabs`（`\toprule`, `\midrule`, `\bottomrule`）；
  - **严禁出现任何垂直竖线 (`|`)**；
  - 数据列小数点对齐或居中对齐，表头清晰明确，表上附标题，表下附数据源与说明；
- **长公式规范折行，杜绝溢出边缘 (Zero Overfull \hbox)**：
  - 严禁单行公式超出页面右边界，长公式必须使用 `aligned`、`split` 或 `multline` 环境在等号 (`=`) 或二元运算符 (`+`, `-`) 处整齐折行；
- **章节层级与大标题强制居中铁律 (Centered Headings)**：
  - **法定八大核心大标题强制居中**：【摘要】、【问题重述】、【问题分析】、【模型假设与符号说明】、【各问题的模型建立与求解】、【灵敏度分析】、【模型的评价】、【参考文献】，这八大一级法定结构的大标题**必须一律强制采用居中对齐以标题形式呈现**（LaTeX 中使用 `\centering` 或 `\ctexset{section={format=\centering\bfseries\Large}}`），严禁左对齐；
  - 二级及以下小节标题（如“5.1 问题一的模型建立与求解”、“5.2 问题二……”）采用常规顶格居左加粗或缩进排版；
  - 严禁滥用破折号（——）、感叹号、冒号碎片式堆叠罗列小标题。
- **严禁大面积空白凑页数与浮动体空隙消除铁律 (Zero Artificial Voids)**：
  - **严禁虚假空白注水凑页数**：严禁通过大面积空白、滥用强制分页（`\newpage`、`\clearpage`）、或人为虚高垂直间距（`\vspace{...}`）来虚假堆砌达到 26–40 页！这是学术评阅极度反感的作弊行为，一经发现直接严重扣分；
  - **图文紧密咬合防悬空断白**：图表浮动体尺寸必须与版面紧密匹配（单图宽度优先取 `0.7–0.85\textwidth`，多图采用并排子图 `0.48\textwidth`，高度受控在页面 0.3~0.4 范围内），严禁因图片过大被挤到下一页而导致上一页底部留出 30%~70% 的大面积悬空空白！
  - **篇幅必须靠真才实学达成**：26–40 页的充实篇幅，必须依靠扎实的机理五步推导、详实的对比实验分析、核心参数灵敏度检验（扰动与重求解由 `math-model-solve` 执行、本技能只取结果入文）与高密度的学术论证段落自然填满，每一页都必须图文并茂、骨肉丰满，绝无任何不自然的断白。
- **严禁出现“注意”、“注：”等说教字眼 (Ban Note Words)**：
  - 论文正文、图表下方、公式说明、表格附注一律**严禁出现“注意”、“注：”、“注1：”、“需要注意的是”等字眼**；
  - 这类词汇带有明显的大模型说教/提示词残留痕迹与口语化口吻，属于学术论文大忌；
   - 需交代的前提或背景，直接以自然客观陈述句推进（如写“根据假设……”、“考虑到实际运输时变特性……”）；公式后统一使用“其中，……”；数据来源直接注明“数据来源：……”，完全融入正文语法句子。

### 3.3 关键核心信息与引导词加粗铁律 (Bold Key Information: Pure Black \textbf)
- **摘要段首各问引导词加粗**：摘要中“\textbf{针对问题一}”、“\textbf{针对问题二}”、“\textbf{针对问题三}”等引导词必须加粗排版，让评阅专家第一秒准确定位各问解答；
- **正文核心量化指标与最优解加粗**：论文正文中的核心数值结果（如最终最优解、提升幅度百分比、置信区间、关键误差指标）必须使用 `\textbf{...}` 适度加粗突显；

## 5. 公式与文字排版铁律（夹心饼与语法连续性）

### 5.1 “夹心饼”三步走范式（严禁孤立空投公式）
1. **前置机理与引导句**：用完整的自然语言说明“为什么要建立此式、物理/经济背景与守恒定律”；
2. **公式居中独立编号**：公式全部居中独立成行，右侧严格附带连续唯一的括号编号；
3. **后置“其中……”符号地毯式解说**：公式下方另起一句，对出现的每一个符号、参数、量纲进行地毯式语义闭环解释。

### 5.2 语法连续性与标点合规
- 公式尾部必须打逗号（`,`）或句号（`。`），公式本身就是语法句子的一部分；
- 正文中出现的变量一律使用标准 LaTeX 数学斜体 `$p_j(t)$`；
- 规划模型必须使用大括号 `\begin{cases}` 矩阵化整齐排列。

### 5.3 段落节奏：长短抑扬美学与分段有度规范
- **该有的分段必须保留（保持版面呼吸感与清晰层次）**：
  - 在逻辑转折、物理过程切换、目标与约束过渡处必须合理分段，版面层次分明，杜绝通篇不分段的死板大泥块；
- **允许单句独立成段，但绝对严禁泛滥**：
  - 仅在陈述核心定理引理、宣布最终最优解数值、或给出关键结论定音时果断使用独立单句成段（10–40 字），重锤定音；
  - 必须克制使用（每节控制在 1–2 处），严禁随手分段，坚决消灭“一两句话就切一段”的 AI 碎片化聊天毛病；
- **模型建立推导以饱满大段贯通推进（150~300 字）**：
  - 模型建立环节必须重点检查，推导主体由结构紧凑、逻辑严密的学术大段贯通推进；
  - 公式前后的机理引出与“其中……”参数释义必须与公式自然熔铸在同一个完整段落中；
- **供稿责任划分（CB-4 / CB-5 衔接铁律）**：公式夹心饼与分段节奏的**供稿责任**在 `math-model-formulate`（G2 推导稿必须按“前有引言因果 → 居中独立编号 → 后有其中释义”与 150~300 字饱满大段成稿供入）；本技能 `math-model-paper` 负责**终稿排版与终检**，供稿不合规时在 G5 打回补写包裹段、重排段落。

## 6. 辅助章节极简精炼铁律（重述、假设与符号、评价与不足）

### 6.1 问题重述 (Problem Restatement)：严格不超过 1 页
- **精简叙述，直击要害**：用学术语言提炼背景核心矛盾与各问任务，**本节篇幅严格控制在 1 页以内**（建议 0.5~0.8 页），严禁长篇大论；
- **坚决杜绝机械照抄**：严禁机械照搬赛题长篇文字背景，背景概述 1 段（100–150 字），随后分问简明概括求解目标即可。

### 6.2 模型假设与符号说明：每条尽量不超过一行，简明条目化
- **模型假设单行极简化**：
  - **每条尽量不超过一行**：直奔边界与简化核心，语言高度凝练，**严禁拖沓写长句，每条假设尽量压在单行以内**；
  - **统一采用 `(1) (2) (3)...` 格式**：杜绝在假设后附加多余长篇辩解；
  - *单行示例*：
    - `(1) 假设蔬菜日内销售损耗率恒定，忽略外界气温短时剧变。`
    - `(2) 假设各批次补货按日结算，次日营业前完成全部到货入库。`
    - `(3) 假设各品类蔬菜需求相互独立，不考虑跨品类的替代效应。`
- **符号说明紧凑规范**：
  - 严禁冗长的符号文字段落叙述，统一使用紧凑整齐的学术三线表（符号 / 定义域与物理含义 / SI 单位），一目了然。

### 6.3 模型的评价：只写优缺点，其余一律不写
- **只写模型的优缺点，其余一律不写**：
  - **彻底删去推广、展望与后续改进等空话**：不写假大空的宏观展望，不写多余的未来设想；
  - 正文严格**仅且只有【模型的优点】与【模型的缺点】**两大板块；
- **格式统一为 `(1) (2) (3)...` 极简输出**：
  - **模型的优点**：
    - `(1) 机理扎实：紧扣供需弹性与时变损耗，模型物理因果明确；`
    - `(2) 求解高效：通过凸化转化保障了全局最优解快速收敛；`
    - `(3) 鲁棒性好：经受住参数 ±20% 扰动测试，容错率高。`
  - **模型的缺点**：
    - `(1) 忽略了极端罕见天气对供应链断链的非线性冲击；`
    - `(2) 稀疏长尾品类需求依赖均值估算，局部精度受限。`
