# 《G0 选题决议卡》填写模板

| 项 | 内容 |
|---|---|
| **产物路径** | `decisions/G0_选题决议卡.md`（相对**项目工作区根**，非 skill 目录） |
| **填写时机** | `G0` 赛前策略与选题决议（72h / 96h 均为 T00:00–T06:00） |
| **填写责任** | `math-model-strategy`（建模手主持，全员确认） |
| **消费方** | `math-model-decomp`（取决议卡进入 G1）、`math-modeling-master` |
| **字段依据** | `math-model-strategy/SKILL.md` §2.4（7 字段 schema，缺一字段即判 G0 未完成） |

> 使用方法：复制本模板到 `decisions/G0_选题决议卡.md`，按 7 字段逐节填写；候选题每题一份第 1 字段评分表。
> 硬约束：锁题时间戳 **≤ T06:00**；一票否决**先于**评分卡执行（S-3）；权重合计恒为 **1.00**。
>
> 路径基准：产物路径与 `data/`、`decisions/`、`state/` 等相对**项目工作区根**；`math-model-strategy/SKILL.md` 等 skill 文件引用相对**skill 仓库根**（两套基准见 CANON §3.1）。
