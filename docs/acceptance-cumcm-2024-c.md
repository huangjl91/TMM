# 真实赛题验收：2024 高教社杯 C 题

## 选题

- 题目：C 题《农作物的种植策略》
- 来源：全国大学生数学建模竞赛组委会 2024 年官方赛题包
- 本机题面：`testdata/cumcm2024/CUMCM2024Problems/C题/C题.pdf`
- 输入附件：`附件1.xlsx`、`附件2.xlsx`
- 结果模板：`附件3/result1_1.xlsx`、`result1_2.xlsx`、`result2.xlsx`

`testdata/` 仅用于本机验收，已加入 Git 忽略规则。

## 为什么用这道题

- 题面含 3 个逐步加深的问题，能够验证按小问识别任务，而不是给整题贴一个标签。
- 两个输入工作簿共 4 个数据表，包含地块、作物、历史种植和经营数据。
- 同时涉及约束整理、优化建模、不确定性与结果比较，适合验证“为什么选模型”。
- 官方结果模板横跨 2024–2030 年，可以检查输出与证据链是否真正落地。
- 数据量适中，首轮验收不会被大文件性能干扰。

## 第一轮范围

只完成问题 1 的情形（1）：超产部分滞销。先验证稳定数据下的种植优化闭环，再扩展到降价销售和不确定性。

## 验收顺序

1. 导入 `C题.pdf`、`附件1.xlsx` 和 `附件2.xlsx`。
2. 检查系统是否识别出 3 个小问，并将问题 1 判断为优化决策问题。
3. 检查数据说明是否区分地块、作物、2023 年种植记录和统计参数。
4. 让用户自行写出目标、决策变量和主要约束，系统只提供追问与依据。
5. 运行一个可复现的基线优化模型，并记录代码、日志、指标和产物。
6. 检查结果能否解释土地利用、轮作、豆类覆盖和销售上限等约束。
7. 将 2024–2030 年方案写入官方 `result1_1.xlsx` 的副本。
8. 检查证据页能否回到题面、输入表、建模决策、运行记录和结果文件。

## 通过标准

- 用户能够说明为什么这是多期混合整数优化问题。
- 系统不虚构附件字段、数值、求解结果或评审结论。
- 任何结论都能追溯到题面、附件数据或实际运行产物。
- 模型失败时给出可操作的修正方向，而不是直接生成论文答案。
- 最终方案满足土地面积、适种条件、避免重茬和三年豆类覆盖等核心约束。
